# Open Canvas
### The Open-Source AI-Native Creative Canvas

OpenCanvas is a free, open-source, node-based AI editor for creators. Connect different AI models, chain them together, and build powerful AI workflows visually — no code required.

## Getting Started

Download Open Canvas, connect your AI models, and start creating. No complicated setup, no technical knowledge needed — just your creativity and the AI models of your choice.

## Installation on macOS (Hackathon Build)

This app isn't distributed via the App Store, so macOS will show a security warning on first launch.

1. Download the **.zip** file.
2. Extract it.
3. **Right-click** `OpenCanvas.app` and select **Open**.
4. Click **Open** in the dialog box.

> **Note:** Double-clicking normally may trigger an "Unidentified Developer" or "Damaged" error. **Right-click → Open** is the required bypass.
